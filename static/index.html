Guia Rápido: Como Classificar o NCM dos Produtos

Este programa serve para corrigir ou preencher o código NCM de vários produtos da sua loja de uma só vez, sem precisar abrir produto por produto no sistema do caixa.

Fique tranquilo: Antes de qualquer alteração, o programa salva automaticamente uma cópia de segurança na pasta backups. Se algo for alterado por engano, é possível recuperar os dados antigos.

Passo 1: Conectar ao Sistema da Loja

  1. Na primeira tela (1. Classificação em Lote), escolha um perfil já salvo em Perfis Salvos (se o técnico já deixou configurado) ou preencha os dados de acesso ao banco da loja.
  2. Clique no botão azul Conectar e Listar Tabelas.
  3. Quando der certo, a etiqueta no canto superior direito mudará de vermelha para verde (Conectado).

Passo 2: Escolher a Lista de Produtos

  1. Em Tabela de Produtos, escolha o cadastro onde ficam os itens da loja (geralmente tem nomes como produtos, estoque ou cad_prod).
  2. Confira se a Coluna Alvo do NCM está apontando para o campo de NCM (o programa costuma marcar sozinho).
  3. Nas caixinhas abaixo, deixe marcadas as informações que você quer ver na tela (por exemplo: código, descrição do produto e NCM atual).

Passo 3: Filtrar Apenas os Produtos Desejados

Use os filtros para separar exatamente os produtos que usam o mesmo NCM, evitando misturar itens parecidos.

Exemplo prático (Padaria):
• Linha 1: Descrição → CONTÉM → digite bolo
• Clique em + Adicionar Condição
• Linha 2: Descrição → NÃO CONTÉM → digite mistura
Resultado: O sistema mostra apenas os bolos prontos e esconde as misturas para bolo em pó.

Depois de montar o filtro, clique em Pesquisar Produtos.

Passo 4: Descobrir o Código NCM Correto (Se Não Souber)

  1. Clique na aba superior 2. Consultar NCM por Setor (Siscomex).
  2. Escolha o Setor do Supermercado (ex.: Padaria, Bebidas, Limpeza, Açougue).
  3. Digite o nome do produto na busca (ex.: refrigerante ou detergente) e clique em Buscar na Tabela.
  4. Ao encontrar a descrição certa na lista, clique no botão Usar NCM. O programa levará o código automaticamente de volta para a primeira tela.
    Passo 4.1 Em caso de dúvidas, consulte o sitio oficial
  1. https://portalunico.siscomex.gov.br/classif/#/sumario?perfil=publico
  2. Aqui você poderá realizar pesquisa para sanar suas dúvidas

Passo 5: Aplicar o NCM nos Produtos Marcados

  1. Na lista de produtos pesquisados, marque a caixinha ao lado de cada item que deve receber aquele NCM (ou marque a primeira caixinha no topo da tabela para selecionar todos de uma vez).
  2. Confira se o número de 8 dígitos está preenchido em Novo Código NCM.
  3. Dica sobre pontos: Observe como os NCMs antigos aparecem na sua lista. Se estiverem com pontos (ex.: 1905.90.90), marque a opção Salvar com pontos. Se estiverem sem pontos (ex.: 19059090), deixe desmarcada.
  4. Clique no botão verde Aplicar NCM nos Marcados e confirme a mensagem na tela.

Dica Extra: Economize Tempo nos Próximos Produtos

Sempre que montar um bom filtro e escolher o NCM certo, clique em Salvar Filtro + NCM na Memória. Da próxima vez (ou em outra loja), basta escolher essa regra na lista verde e clicar em Carregar Regra que o sistema faz a busca sozinho.
